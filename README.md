# 海报编辑器
https://image-editor-liart-alpha.vercel.app

## 开发环境

- Vue 3 Javascript模式
- Vite 开发环境&打包工具
- Less CSS预编译库
- Fower 运行时样式原子类 https://github.com/forsigner/fower
- 图床 https://unsplash.com/

## 安装

- 安装 `npm install`

## 指令
- 运行开发服务器：`npm run dev`
- 打包 ： `npm run build`
- 运行本地测试服务器 `npm run serve`
- 打包库 `npm run build:lib`
- 运行库的本地测试服务器 <= dist-lib：`npm run serve:lib`
